# Privacy and Sanitization

Before publishing a private setup:

- replace absolute home paths with `$HOME` or variables;
- remove usernames, emails, repository URLs, tokens, keys, IDs, and local PIDs;
- never publish authentication files;
- never publish raw memory databases or transcripts;
- convert machine-specific commands into parameterized scripts;
- review Git history, not only the working tree;
- scan generated archives before release.
